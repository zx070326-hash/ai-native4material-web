# 光热超材料：两个固定构造的仿真结果

**[在线阅读成果页](https://zx070326-hash.github.io/ai-native4material-web/)**

更新至2026-11-02。本轮固定材料、布局与器件，只补材料复谱、组装界面、VO₂内态及关键光路。

| 问题 | 本轮结果 | 适用口径 |
|---|---|---|
| 透明辐射制冷 | VIS总T **72.7904%**；NIR总T **28.0789%**；MIR法向A **0.587930** | 统一材料复谱与直接接触，完整RCWA耦合；三阈值通过 |
| 电压/温度双响应 | 参考VIS/NIR主调控 **42.5077/21.1729 pp**；计光路后的条件下限 **41.0532/20.7111 pp** | 同一驱动、1320s热史、VO₂内态与收光口；新增侧轨及返回未耗尽余量 |

题二再计局部材料敏感性及相位诊断后，NIR诊断下端约 **20.6242 pp**。NIR电压串扰的条件带差上界为 **0.455833 pp**；原题没有数值解耦容差，直接报告交叉响应。

波段暂用VIS 0.38–0.78µm、NIR 0.78–2.5µm、MIR 8–13µm，采用波长均匀平均。题一总T包含衍射，VIS零级T约48.73%；题二光路范围与材料敏感性具有各自的模型条件。报告明确区分参考四态、窗口修正和条件预算。结果属于仿真，未声称实验制成或无近似全域Maxwell验证。
